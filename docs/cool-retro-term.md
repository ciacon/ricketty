# Cool Retro Term

Cool Retro Term is optional. Ricketty works in a normal terminal; the emulator
only provides presentation effects.

## Suggested manual profile

- Start with a readable monospace font and a terminal window large enough for
  the dashboard's two columns.
- Use a restrained green-on-dark palette.
- Enable fullscreen if preferred.
- Add scanlines, bloom, and noise sparingly: the text should remain readable.

Run Ricketty inside that terminal:

```bash
uv run ricketty
```

Use `Ctrl-C` or `Ctrl-Q` to quit. Cool Retro Term configuration remains local
user preference and is not part of the Ricketty source tree.
